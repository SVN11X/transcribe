# docs

Intent and knowledge of this repository, for people and AI tools.

- Goes here: `goals.md` (what this repository is for, written by the owner), `glossary.md` (shared terms), `assumptions.md` (things taken as true without confirmation), `decisions/` (one record per decision), `specs/` (specifications for large changes), and other documentation about the project.
- Does not go here: user-facing content of the product, generated build output.
- Naming: kebab-case, for example `api-overview.md`.
