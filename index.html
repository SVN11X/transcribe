Preparar un video para dárselo a una IA

Sube un video y esta página arma, ordenado por tiempo, la transcripción de lo que se dice y una imagen de la pantalla en cada momento. Descargas todo en un ZIP para dárselo a una IA que pueda ver imágenes. La IA lee las imágenes directamente, así que el texto que de verdad importa es el audio transcrito. Todo ocurre en tu navegador, nada se sube a internet.

Cómo subir esta página a GitHub Pages
  1. Crea un repositorio nuevo en GitHub, por ejemplo preparar-video.
  2. Sube este archivo con el nombre index.html a la raíz del repositorio.
  3. Entra a Settings, luego Pages, y en Source elige la rama main y la carpeta / (root).
  4. Espera un minuto. GitHub te muestra la dirección pública, algo como https://tu-usuario.github.io/preparar-video/.
  5. No necesitas nada más. El modelo de transcripción y el lector de texto se descargan solos desde internet la primera vez.
